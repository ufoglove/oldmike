# EvaluationSuiteIndex：AI 語義評估、三目標回歸與評估資料治理

## 1. 評估資料治理
- **資料集隔離**：嚴格劃分開發集（Development Set）、固定回歸集（Regression Set）與保留集（Holdout Set）。
- **保留集污染防護**：若開發過程中曾查閱保留集個案，必須記錄暴露狀態（`holdoutExposureRef: HOLDOUT_EXPOSED`）並更換新保留案例，嚴禁將已調參案例視為未見測試。
- **隱私與訓練邊界**：使用者私稿、訪談逐字稿、專家審查意見嚴禁回流為模型訓練資料，亦不得跨專案存入共享向量庫。測試優先使用合成最小重現案例（Synthetic Fixtures）。

## 2. 三目標關鍵旅程回歸規格
1. **期刊路線 (`JOURNAL_SCI_SSCI`)**：
   - **無真實結果**：保持研究規劃狀態，嚴禁捏造受試樣本、統計量與 Results 篇章。
   - **有真實結果**：嚴格綁定 `ResultFact`，精確保留 $N$、方向、未顯著結果與限制；措辭修改不得更動科學實質。
2. **國科會一般專題路線 (`NSTC_GENERAL`)**：
   - 不要求在申請草稿階段先完成未來三年之實驗結果。
   - 未知之主持人過往成果、設備單價保持待補，不隨意套用通用數字；時程語言使用預期式而非已完成式。
3. **教育部教學實踐研究路線 (`MOE_TPR`)**：
   - 保持主授課程、教學現場問題、真實基線數據、教學介入與學習評量之一致性。
   - 課堂數據缺失時標記 `UNKNOWN`，嚴禁回退為純學術期刊模板，亦不得以通用教育文獻替代本班基線。

## 3. 語義評估準則 (Semantic Rubric)
- **多種措辭寬容度**：只要科學意涵、引用依據與限制保留一致，允許語法與修辭之多樣性，不因字串未完全相同判為 FAIL。
- **爭議仲裁機制**：當模型對來源解讀存在分歧時，標記 `REQUIRES_ADJUDICATION`，維持 `PENDING_HUMAN_REVIEW`，嚴禁由多個 LLM 投票直接篡改稿件。
