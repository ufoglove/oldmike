# C19 durable transport boundary

Beta2 A1_C1 is an additive route and page. The frozen C19 product flow remains byte-identical and does not import the Beta2 durable transport.

This candidate proves the durable coordinator, restricted disposable PostgreSQL repository, real local Better Auth session, and Beta2-only user interface together. It does not claim that the C19 interface has been rewired to durable storage. Reusing the C19 interface with this transport requires a separate product decision because changing any frozen C19 leaf is outside A1_C1 authority.

Live OpenClaw, Neon, N8N, scholarly providers, formal research writes, deployment, Professor UAT, and release remain disabled.
